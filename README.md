# photon-dissector-wireshark
Wireshark Lua dissector for the Photon Engine UDP binary protocol

## Description

Tailored for the traffic of a single social VR platform.

### Installation
1. Find the Wireshark Lua scripts directory: `Help` -> `About Wireshark` -> `Directories` -> `Personal Lua Plugins`
2. Copy `photon_dissector.lua` into that directory
3. Reload Wireshark with `CTRL+SHIFT+L`

### References
- [Photon Engine Binary Protocol Reference](https://doc.photonengine.com/realtime/v5/reference/binary-protocol)
- [Photon TCP and UDP Port Numbers](https://doc.photonengine.com/server/v5/operations/tcp-and-udp-port-numbers)

## Описание

Диссектор протокола Photon Engine для Wireshark.

Адаптирован под трафик одной социальной VR платформы.

### Установка
1. Папка Lua-плагинов Wireshark: `Help` -> `About Wireshark` -> `Directories` -> `Personal Lua Plugins`
2. Скопировать `photon_dissector.lua` в эту папку
3. Перезагрузить плагины: `CTRL+SHIFT+L`

### Ссылки
- [Photon Engine Binary Protocol Reference](https://doc.photonengine.com/realtime/v5/reference/binary-protocol)
- [Photon TCP and UDP Port Numbers](https://doc.photonengine.com/server/v5/operations/tcp-and-udp-port-numbers)
